# 📖 BTBoy 使用教程

## 一、准备

1. **创建机器人**：私聊 `@BotFather` → `/newbot` → 取名拿 Token
2. **创建频道**：Telegram 里新建一个频道（公开/私密均可）
3. **把机器人加为频道管理员**：频道设置 → 管理员 → 添加 → 搜你的机器人，勾选"发布消息"
4. **拿到你的数字 ID**：私聊 `@userinfobot`，第一条消息里就是你的用户 ID

## 二、部署

```bash
docker run -d --name btboy --restart unless-stopped \
  -e TELEGRAM_BOT_TOKEN=你的Token \
  -e ADMIN_ID=你的数字ID \
  -v $PWD/data:/data \
  wucaicai/btboy:latest
```

数据保存在 `./data`（SQLite + 日志），备份只需拷走这个目录。

**更新到新版本**（数据保留，库表自动迁移）：

```bash
docker compose pull && docker compose up -d
# 或：docker pull wucaicai/btboy:latest && docker rm -f btboy && docker run ... （挂载原 ./data）
```

> `docker restart` 不会拉取新镜像，必须先 `pull` 再重建容器。

## 三、首次配置（5 步）

### 1. 注册管理员

私聊机器人发：

```
/admin
```

第一个使用者即成为管理员（如果设置了 `ADMIN_ID` 可跳过）。

### 2. 绑定推送频道

```
/bind
```

机器人会提示两种方式任选其一：

- **转发一条**来自目标频道的消息给机器人
- 或直接**输入频道 ID**（形如 `-1001234567890`）

> 必须先让机器人成为频道管理员，否则推送会失败。

### 3. 添加订阅（2 屏搞定）

```
/sub https://bangumi.moe/rss/tags/xxxx
```

机器人自动识别番名，默认配置已填好：

```
识别到的番名可能是:
再見菈菈 / Sayonara Lara

[✅ 用默认配置]  ← 直接完成
[⚙️ 自定义] [取消]
```

- 点 **✅ 用默认配置**：从第01话起、简繁每次问、全部片源，立即添加。
- 点 **⚙️ 自定义**：进入一屏配置，改哪项点哪项，最后点 ✅ 完成：

```
⚙️ 订阅配置
起始集: 第01话 · 简繁: 每次问 · 片源: 全部
包含词: 无 · 排除词: 无 · 封面: 已选

[番名] [起始集] [简繁]
[片源] [包含词] [排除词]
[封面] [✅ 完成]
```

> 番名识别不准（比如识别成了字幕组名）时，点 **番名** 手动输入正确名字，机器人会按新名字重新搜索 TMDB 封面让你确认。

完成后订阅生效，机器人每 5 分钟轮询一次。

### 4. 验证

```
/test     → 发一条测试消息到频道
/status   → 查看订阅数 / 频道 / 开关状态
/push 1   → 立即拉取订阅 #1 并推送
```

### 5. 查看推送效果

频道里会收到固定格式消息：

```
再見菈菈 / Sayonara Lara 第07话
[黒ネズミたち · Baha · 1080P · x264]

magnet:?xt=urn:btih:dd8d006b...&tr=http%3A%2F%2Ftr.bangumi.moe...
```

## 四、冲突询问：机器人让你选

当同一集出现**多个来源/版本**时（如 ABEMA / CR / Baha 各发了一版第07话），机器人会发消息问：

```
🧐 再見菈菈 / Sayonara Lara 第07话 发现多个来源/版本
1 · v1 · ABEMA · 1080P · x264 · …d7f10ead
2 · v1 · CR · 1080P · x264 · …b071303a
3 · v1 · Baha · 1080P · x264 · …dd8d006b

要推送哪个？
[①] [②] [③] [全部] [跳过] [稍后]
```

- 点 `①/②/③` → 只推选中的那个，并记住该订阅的偏好，之后同款情况自动套用
- 点 `全部` → 全推
- 点 `跳过` → 这集不要了
- 点 `稍后` → 下次轮询再问

已推过的集数出现新版本（如 07v2）会单独询问是否追加。

## 五、想让订阅更精准

- **只要某个片源**：`/edit <id>` → 包含词填 `Baha`（或 `CR`），之后只推 Baha 的
- **不要某类资源**：`/edit <id>` → 排除词填 `生肉`
- **从第几集开始**：`/edit <id>` → 起始集
- **改番名**：`/edit <id>` → 番名，输入正确名字后会自动按新名字重搜封面供你重选
- **只追最新**：订阅时起始集填当前集数，旧集全跳过

## 六、推送记录 / 待办 / 备份

- **推送回执**：机器人自动推到频道后，会给管理员发一条「📤 已推送 第xx话」的汇总回执，不必盯着频道。
- **`/history [id] [n]`**：查看最近推送记录（集数 / 版本 / 简繁 / 时间）。不填 id 看全部，如 `/history 1 30`。
- **`/pending`**：查看所有待你选择的冲突项，点「重发」找回被聊天淹没的询问。
- **`/export`**：导出一份订阅 JSON（文件），换机器时用 **`/import`** 粘贴内容或发回该文件即可恢复（自动按 RSS 链接去重）。
- **`/status`**：除开关外，还显示上次轮询时间与下次预计时间。

## 七、推荐开关

| 设置 | 命令 | 用途 |
|---|---|---|
| 跳过 07.5 特殊集 | `/skiphalf on` | 不推总集篇/特别篇 |
| 遗漏检测 | `/gap on` | 某集漏推时提醒你 |
| 摸鱼检测 | `/slack 7` | 一周没更新提醒，发现断更 |
| 自动停用 | `/autodisable on` + `/bgm <id> <bgmid>` | 全集推完自动停用，不空转 |
| 备用 RSS | `/backup <id> <rss>` | 主源摸鱼时用备用源兜底 |

## 八、日志与排障

```
/logs     查看最近日志（可 /logs 50）
/status   查看运行状态
```
